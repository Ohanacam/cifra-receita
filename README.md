# Cifra Receita

Projeto da atividade de desenvolvimento de uma cifra de segurança.

## GitHub Pages

Este projeto foi adaptado para funcionar 100% no navegador, sem Flask e sem Python.

Arquivos necessários:
- `index.html`
- `script.js`
- `style.css`

No GitHub:
1. Crie um repositório.
2. Envie os três arquivos para a raiz do repositório.
3. Vá em Settings > Pages.
4. Em Source, escolha `Deploy from a branch`.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Salve.

O site será publicado no endereço:
`https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`
