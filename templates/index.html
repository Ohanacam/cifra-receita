Como funciona

Chave
Embaralha os ingredientes e define qual letra é qual ingrediente.
Palavras
Cada palavra vira uma etapa do modo de preparo.
Letras
Cada letra vira um ingrediente. Maiúscula acrescenta "de primeira".
Acentos
Viram medidas: "uma pitada de", "um toque de", "uma porção de", "uma colherada de", "um punhado de".
Números
A cada dois dígitos vira um tempo de cozinha (fogo, liquidificador, forno, geladeira).
Pontuação
Vira uma instrução curta, como "Mexa bem." para o ponto.
Finalização
Guarda o total de letras e palavras para conferir a mensagem ao descriptografar.
